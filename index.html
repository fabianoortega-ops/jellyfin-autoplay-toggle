A Jellyfin plugin that adds a repeat button directly in the video player — toggle next episode autoplay without leaving the screen.

✨ Features
Everything you need, nothing you don't
🎮

In-Player Button

The repeat icon sits between the favorite and subtitle buttons. One click toggles autoplay — no menus, no navigation.

⚡

Instant & Persistent

Changes apply immediately to your account and sync across all sessions. Bright icon = on, dim icon = off.

🌍

25 Languages

Auto-detects your browser language. Supports EN, PT, DE, FR, ES, IT, RU, ZH, JA, KO, and 15 more.

🔧

REST API

Exposes /AutoPlay/Status and /AutoPlay/Toggle for automation scripts and home assistants.

📊

Dashboard Toggle

Also accessible from the Jellyfin sidebar for managing autoplay state without opening a video.

🚀

Hot Reload

JavaScript updates deploy via git push — no Jellyfin server restart needed for UI changes.

⚡ Installation
Ready in under 2 minutes
⚠️ Requires the JavaScript Injector plugin by n00bcodr. Install it from the Jellyfin Plugin Catalog first.
1

Add the repository

Go to Dashboard → Plugins → Repositories → + and add:

https://fabianoortega-ops.github.io/jellyfin-autoplay-toggle/manifest.json
2

Install the plugin

Go to Catalog, find AutoPlay Toggle and click Install.

3

Restart Jellyfin

Restart the server once to load the plugin. The button appears automatically in the player.
